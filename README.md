# GitHub User Activity

Use GitHub API to fetch user activity and display it in the terminal.

## Description

In this project, we build a simple command line interface (CLI) to fetch the recent activity of a GitHub user and display it in the terminal. This project will helped me to practice my programming skills, including working with APIs, handling JSON data, and building a simple CLI application.

This is based on project at https://roadmap.sh/projects/github-user-activity.

# Usage Guide

```sh
go build . -o github-activity
```

```sh
./github-activity kabirnayeem99
```
